# Interlocked consumer fixture

`TUnitCounter.cs.txt` is an unchanged copy of TUnit's `TUnit.Core.Helpers.Counter`
from `src/TUnit.Core/Helpers/Counter.cs`. The MIT license is retained alongside
it. The fixture exercises the real counter and notification behavior against
the available Interlocked contract, without adding a library-specific shim.
